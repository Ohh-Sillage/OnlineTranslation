# 安装文档

本文档指导从零开始安装并运行"在线视频实时字幕翻译"项目（方案 B：本地服务版）。

## 一、环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 |
| 浏览器 | Microsoft Edge（Chromium 内核） |
| Python | 3.10 ~ 3.12（推荐 conda 管理环境） |
| 硬件 | CPU：4 核以上（识别速度与核数正相关）；内存：8GB 以上 |
| 网络 | 首次运行需下载 Whisper 模型（约 500MB）；默认翻译接口需联网 |

> 说明：AMD 显卡用户保持 CPU 模式即可（本机 `pyAMD6650` 环境不影响）；NVIDIA 显卡可选 CUDA 加速（见第六节）。

## 二、安装本地服务

### 2.1 创建独立 conda 环境（推荐）

打开 `cmd`（或 Anaconda Prompt），执行：

```cmd
call conda create -n ot python=3.12 -y
call conda activate ot
```

> 若未安装 conda，也可使用系统 Python 直接安装（跳过此步，第 2.2 节直接用 `python`）。

### 2.2 安装依赖

进入项目目录并安装依赖：

```cmd
cd /d C:\Users\Latecomer\Desktop\共享\Project\OnlineTranslation
pip install -r server\requirements.txt
```

主要安装内容：fastapi、uvicorn、faster-whisper、numpy、requests。

**验证安装**：

```cmd
python -c "import faster_whisper, fastapi, numpy; print('依赖安装成功')"
```

### 2.3 （可选）本地离线翻译 NLLB 依赖

默认使用免费在线翻译接口链（微软 Edge → MyMemory → Google，无需 key），**不需要**本节内容。
若想完全离线翻译（本地 NLLB-200 模型，约 2.5GB 下载），额外安装：

```cmd
pip install transformers torch
```

并在启动服务时设置环境变量 `OT_TRANSLATOR=nllb`（见 3.3 节）。

## 三、启动本地服务

### 3.1 启动

```cmd
call conda activate ot
python server\main.py
```

首次启动会显示：

```
本地服务启动: http://127.0.0.1:8765  (模型: small, 翻译: auto)
INFO:     Uvicorn running on http://127.0.0.1:8765
```

> 模型为**懒加载**：点击扩展"开始翻译"后才会下载并加载模型（约 1~3 分钟），
> 之后每次启动即载即用。首次加载时的日志：
> `[ASR] 加载模型 small ...` → `[ASR] 模型加载完成`。

### 3.2 验证服务

浏览器打开 `http://127.0.0.1:8765/health`
应返回：

```json
{"status": "ok", "asr_model": "small", "device": "cpu", "translator": "auto"}
```

### 3.3 常用启动配置（环境变量）

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `OT_MODEL` | `small` | 模型大小：tiny / base / small / medium / large-v3 |
| `OT_DEVICE` | `cpu` | `cpu` 或 `cuda`（仅 NVIDIA 显卡） |
| `OT_COMPUTE` | `int8` | CPU 用 int8；cuda 用 float16 |
| `OT_TRANSLATOR` | `auto` | `auto`（免费接口链）/ `nllb`（本地离线） |

示例（cmd 语法）：

```cmd
set OT_MODEL=medium
set OT_TRANSLATOR=nllb
python server\main.py
```

## 四、加载浏览器扩展

1. 打开 Edge，地址栏输入 `edge://extensions` 回车；
2. 打开左下角 **"开发人员模式"** 开关；
3. 点击 **"加载解压缩的扩展"**；
4. 选择本项目的 `extension` 文件夹（即包含 `manifest.json` 的目录）；
5. 加载成功后，工具栏出现扩展图标（蓝色对白气泡）。

> 每次修改扩展代码后，在 `edge://extensions` 页面点击该扩展卡片上的 **刷新按钮** 重新加载。

## 五、验证整体流程

1. 确认本地服务已在运行（第三节）；
2. 打开任一视频网站（如 B 站、YouTube）并播放视频；
3. 点击扩展图标 → 选择源语言（日语/英语/自动）→ 点 **"开始翻译"**；
4. 视频播放约 2~5 秒后，页面底部中央出现双语字幕；
5. 停止翻译：再次点击扩展图标 → **"停止翻译"**。

## 六、（可选）NVIDIA CUDA 加速

若显卡为 NVIDIA（GTX 10 系列以上，显存 6GB+），可启用 GPU 加速：

```cmd
call conda activate ot
pip install nvidia-cublas-cu12 nvidia-cudnn-cu12
set OT_DEVICE=cuda
set OT_COMPUTE=float16
python server\main.py
```

> 注意：CUDA 加速需要本机已安装 NVIDIA 显卡驱动（无需完整安装 CUDA Toolkit）。
> AMD 显卡暂不支持 faster-whisper GPU 加速，保持默认 CPU 配置。

## 七、常见问题（FAQ）

### Q1: 模型下载失败 / 下载很慢

faster-whisper 默认从 HuggingFace 下载模型。国内网络可设置镜像：

```cmd
set HF_ENDPOINT=https://hf-mirror.com
python server\main.py
```

也可提前手动下载模型到缓存目录，或将 `config.py` 中 `MODEL_SIZE` 改为已有的本地模型路径。

### Q2: 端口 8765 被占用

```cmd
netstat -ano | findstr 8765
```

找到占用进程 PID 后结束它，或修改 `server/config.py` 中 `PORT`（需同步修改 `extension/offscreen.js` 的 `WS_URL` 和 `manifest.json` 的 `host_permissions`）。

### Q3: 扩展加载报错 "Manifest 文件无效"

检查是否选择了包含 `manifest.json` 的 `extension` 文件夹本身（不要选项目根目录）。

### Q4: 点击"开始翻译"没有反应

- 检查本地服务是否启动（`http://127.0.0.1:8765/health`）；
- 在 `edge://extensions` 中确认扩展图标已存在且无红色错误提示；
- 点击扩展图标查看"本地服务"徽标是否为绿色"正常"。

### Q5: 字幕显示不出来，但服务有日志

- 确认当前标签页为**视频正在播放**的标签页；
- 部分网站（全屏视频、iframe 嵌套）可能需要退出全屏后重试；
- 刷新页面后重新"开始翻译"。

### Q6: DRM 视频（Netflix、Disney+ 等）无法识别

DRM 版权保护会屏蔽音频捕获，这是浏览器安全机制，无法绕过，请改用非 DRM 源观看。

## 八、卸载

1. 服务端：停止终端窗口（Ctrl+C）即可；删除环境：`call conda env remove -n ot -y`；
2. 扩展：在 `edge://extensions` 中点击该扩展的 **"删除"**；
3. 可选：删除 `%USERPROFILE%\.cache\huggingface` 中的模型缓存以释放磁盘空间。
