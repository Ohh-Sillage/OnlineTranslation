# 使用指南

本文档介绍"在线视频实时字幕翻译"扩展的日常使用、参数调优与常见问题排查。
使用前请确保已完成 [安装文档](./安装文档.md) 的全部步骤。

## 一、界面说明

点击浏览器工具栏的扩展图标，弹出控制面板：

| 区域 | 功能 |
|---|---|
| 顶部徽标 | 显示本地服务连接状态（绿色=正常 / 红色=未连接） |
| 源语言 | 日语 / 英语 / 自动 单选 |
| 开始/停止按钮 | 切换翻译状态（蓝=开始，红=停止） |
| 字幕字号滑块 | 调整页面字幕显示字号（14~32px，实时生效并记忆） |
| 字幕预览框 | 显示最近一条翻译结果 |
| 底部提示 | 显示与本地识别服务的 WebSocket 连接状态 |

## 二、基本使用流程

1. **启动本地服务**（在 cmd 中）：
   ```cmd
   call conda activate ot
   python server\main.py
   ```
   保持该窗口常开（最小化即可），服务关闭则字幕功能不可用。

2. **打开视频**：在 Edge 中打开目标视频页面（B 站、YouTube、普通 HTML5 视频均可），**开始播放**。

3. **开始翻译**：点击扩展图标 → 选择源语言 → 点 **"开始翻译"**。

4. **查看字幕**：页面底部中央出现双语字幕（上方中文翻译、下方原语言原文）。

5. **停止翻译**：点击扩展图标 → **"停止翻译"**；或直接关闭/刷新视频页面。

> 提示：切换标签页后字幕只显示在"开始翻译"时所在的标签页。换视频页需重新点击开始。

## 三、语言切换

- **日语**：动漫、日剧、日语直播推荐；
- **英语**：英文视频、教程、直播推荐；
- **自动**：Whisper 自动检测语言（适合双语混排视频，首次识别稍慢）。

切换语言后需 **停止 → 重新开始** 才会生效。

## 四、字幕显示规则

- 字幕按**话轮（静音分段）**显示：说话人停顿约 0.6 秒后识别并刷新字幕；
- 一条字幕默认显示 **7 秒**，若 7 秒内无新字幕则自动淡出；
- 中文译文在上、原文在下，原文较暗；
- 字号通过扩展面板滑块调整，设置会保存。

## 五、性能调优

识别速度与精度由本地服务配置决定，修改后需重启服务。

### 5.1 识别模型选择（OT_MODEL）

| 模型 | 体积 | CPU 实时率* | 精度 | 适用场景 |
|---|---|---|---|---|
| tiny | ~75MB | 约 8x | 低 | 低配机器快速预览 |
| base | ~145MB | 约 4x | 一般 | 英语视频 |
| **small（默认）** | ~465MB | 约 1.5x | 良好 | 日常日语/英语，**推荐** |
| medium | ~1.5GB | 约 0.4x | 优秀 | 高配 CPU / NVIDIA GPU |
| large-v3 | ~3GB | 约 0.1x | 最佳 | 仅建议 GPU 用户 |

\* 实时率 = 处理速度 / 音频时长，>1 表示能跟上实时播放（4 核 CPU 参考值）。

启动示例：

```cmd
set OT_MODEL=medium
python server\main.py
```

### 5.2 翻译策略选择（OT_TRANSLATOR）

| 策略 | 说明 | 依赖 |
|---|---|---|
| `auto`（默认） | 免费接口链：微软 Edge → MyMemory → Google，逐个回退 | 需联网 |
| `nllb` | 本地 NLLB-200 模型，完全离线 | 需另装 transformers + torch |

```cmd
set OT_TRANSLATOR=nllb
python server\main.py
```

### 5.3 NVIDIA GPU 加速

```cmd
set OT_DEVICE=cuda
set OT_COMPUTE=float16
python server\main.py
```

### 5.4 延迟与字幕节奏

字幕滞后主要来自：静音切段等待（≤0.6s）+ 识别耗时 + 翻译耗时。
若感觉字幕太"黏"，可调低 `server/config.py` 中 `VAD_MIN_SILENCE_S`（如改为 0.4，更快切段，但可能把句子切碎）；反之调高则句子更完整。

## 六、故障排查

### 症状 1：面板显示"本地服务未连接"

- 服务未启动 → 启动服务（见第二节）；
- 端口被占用 → 见安装文档 FAQ Q2；
- 服务刚启动（模型加载中）→ 稍等片刻，徽标会自动刷新。

### 症状 2：字幕一直不出，但服务日志有识别输出

- 确认字幕发送到的是"开始翻译"时的那个标签页；
- 页面全屏时部分站点可能遮挡字幕层，退出全屏观察；
- 刷新页面后重新开始翻译。

### 症状 3：识别结果乱码 / 明显错误

- 检查源语言选择是否正确（日语视频选了英语会乱）；
- 视频背景音乐/噪音大时，换成更大的模型；
- 日语音频建议至少 `small` 模型，`base` 以下精度不足。

### 症状 4：字幕显示延迟 5 秒以上

- CPU 满载：关闭其他占用程序，或换小模型（`OT_MODEL=base`）；
- 翻译接口网络慢：可切换 `nllb` 本地翻译（离线更快）；
- 静音切段等待：调整 `VAD_MIN_SILENCE_S`。

### 症状 5：B 站/YouTube 正常，但某网站无字幕

- 该网站可能使用了 DRM 保护（无法捕获音频）；
- 或视频在 iframe 中播放，切换标签页后需重新开始。

## 七、进阶：命令行直接测试服务

不打开浏览器，也可用脚本直连服务验证识别链路（排查问题时很有用）：

```cmd
call conda activate ot
python -c "import numpy as np, asyncio, json; from vad import EnergyVAD; v=EnergyVAD(); import config; print('VAD OK', config.MODEL_SIZE)"
```

> 说明：`server/main.py` 是 WebSocket 服务端，运行于 `127.0.0.1:8765`，
> 浏览器扩展通过 `ws://127.0.0.1:8765/ws` 推送 PCM 音频并接收字幕 JSON。

## 八、日常使用清单

- [ ] 看视频前先启动本地服务（一行命令）
- [ ] 选对源语言（日语/英语/自动）
- [ ] 在视频页面点击"开始翻译"
- [ ] 停止翻译后再关闭视频页（可选，直接关页也可）
